# 최고의 라면 디자인 메모

## 스케치 테마

- 전체 톤은 손으로 그린 캐주얼 게임 느낌을 유지한다.
- 검은 외곽선은 냄비, 가스레인지, 결과지처럼 구조를 잡는 요소에 주로 사용한다.
- 점수에 직접 영향을 주는 요소는 다른 오브젝트보다 스케치 표현을 더 강하게 준다.
  - 물 높이
  - 끓는 타이밍
  - 라면 투입 타이밍
  - 면 익힘과 불어터짐
- 물은 외곽선 없이 연한 파란색 채움 위에 얇은 사선 빗금을 얹는다.
- 스프 투입 후 국물은 연한 주황 계열 채움과 주황 계열 빗금으로 바꾼다.
- 면발은 노란 계열 해칭으로 채우고, 회색 심지처럼 보이는 내부선은 피한다.
- 면발 외곽선도 검정/회색보다 노란 계열을 사용해 라면 덩어리처럼 보이게 한다.
- 빗금은 굵고 듬성듬성한 패턴보다, 얇은 펜선이 촘촘히 쌓인 느낌이 좋다.

## 라면 표현

- 입력 흐름은 물 넣기 홀드/떼기 후 자동 점화, 끓는 순간 라면 투입 탭, 적정 익힘에서 불 끄기 탭으로 유지한다.
- 처음 투입된 면은 빨간 기준선 길이의 절반 정도 너비에서 시작한다.
- 익으면서 점점 빨간 기준선 길이만큼 넓어진다.
- 퍼짐 이후에는 더 넓어지기보다 면발이 굵어지고 무거워지는 방식으로 불어터짐을 표현한다.
- 면은 냄비 바닥에 붙이지 않고, 물높이 근처에 떠 있는 느낌을 유지한다.
- 처음 투입된 면의 시각적 높이는 손잡이 절반 정도로 고정한다.

## 결과지

- 결과지는 짧고 게임답게 유지한다.
- 점수는 물 높이, 투입, 익힘 세 항목을 보여준다.
- 상세 설명이나 다음 판 목표 문장은 넣지 않는다.
- 각 게이지 하단에는 짧은 평가 타이틀만 표시한다.
  - 예: 물 감각 좋음
  - 예: 투입이 살짝 늦음
  - 예: 익힘 좋음
- 점수 아래 첫 평가는 `시식평`으로 표시한다.

## 점수

- 최종 표시 점수는 세 항목의 평균이 아니라 곱연산 기반으로 계산한다.
- 최고점은 `10000점` 만점이다.
- 예: 물 높이 98, 투입 56, 익힘 97이면 최종 표시 점수는 `98 * 56 * 97 / 100 = 5323점`이다.
- 한 항목이 크게 흔들리면 최종 점수가 확 떨어지는 구조를 유지한다.
- 시식평과 광고 실패 판정처럼 등급 판단이 필요할 때만 내부적으로 `최종 표시 점수 / 100` 환산값을 사용한다.
- 물 점수는 내부 물량값이 아니라 화면상 물 표면이 빨간 기준선에 얼마나 가까운지로 계산한다.

## 광고와 크래시 리포팅

- 웹 프로토타입에서는 네이티브 SDK를 직접 붙이지 않는다.
- 네이티브 래퍼가 생기면 `window.BestRamyeonAdMob.showInterstitial` 브릿지로 광고를 연결한다.
- 실패 판정은 76점 미만이며, 실패 3회마다 인터스티셜 광고를 시도한다.
- 네이티브 래퍼가 없을 때는 광고 UI를 띄우지 않는다.
- 오류 수집은 `window.BestRamyeonCrashlytics.recordError` 브릿지를 우선 사용한다.
