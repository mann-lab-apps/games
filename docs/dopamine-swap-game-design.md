# 도파민 스왑 게임 기획

## 한 줄 설명

라운드마다 제한 시간 안에 내 카드를 고르고, 컴퓨터의 랜덤 점수보다 높으면 누적 점수를 들고 다음 라운드로 넘어가는 하이리스크 카드 비교 게임.

## 핵심 재미

플레이어가 느껴야 하는 감정은 "이번 카드면 이길까?", "아껴야 하나?", "한 판만 더 가면 기록인데"이다.

이 게임은 복잡한 카드 배틀이 아니다. 짧은 제한 시간, 불완전한 정보, 누적 점수를 잃을 수 있다는 압박으로 즉각적인 선택 재미를 만든다.

## 기본 루프

1. 라운드가 시작되면 컴퓨터 점수 또는 점수 힌트가 정해진다.
2. 플레이어는 제한 시간 동안 현재 카드를 스와이프해 랜덤으로 바꾼다.
3. 시간이 0초가 되는 순간 화면에 떠 있는 카드가 내 카드가 된다.
4. 내 카드 점수가 컴퓨터 점수보다 높으면 승리한다.
5. 승리하면 해당 라운드 점수가 누적 점수에 더해지고 다음 라운드로 간다.
6. 패배하면 런이 종료되고, 직전까지 얻은 누적 점수가 최종 Score가 된다.
7. 최고 Score를 로컬에 저장한다.

## MVP 규칙

- 입력: 화면에 보이는 카드 한 장을 스와이프해 랜덤으로 바꾼다.
- 확정: 시간이 0초가 되는 순간 화면에 떠 있는 카드로 자동 비교한다.
- 내 카드 점수: 1-100 사이 정수.
- 컴퓨터 점수: 라운드마다 생성되는 1-100 사이 정수.
- 승리 조건: 내 카드 점수 > 컴퓨터 점수.
- 동점은 패배로 처리한다.
- 제한 시간은 선택 시간이 아니라 스왑 시간이다.
- 패배 시 이번 라운드 점수는 누적하지 않는다.
- Best Score는 최고 누적 점수다.

## 카드 모델 후보

첫 MVP는 매 라운드 한 장의 카드만 화면에 보여준다. 플레이어가 스와이프하면 1-100 전체 범위에서 새 카드가 랜덤으로 튀어나오고, 타이머가 0초가 되는 순간 떠 있는 카드로 승부한다.

```txt
내 카드:  71
상대:    ?? 또는 62
0초 카드: 71
결과:    승리, 누적 +71
```

초기 카드 생성:

- 매 라운드 시작 카드 1장을 1-100 전체 범위에서 랜덤 생성
- 스와이프할 때마다 1-100 전체 범위에서 현재와 다른 카드가 랜덤으로 표시
- 카드 점수는 1-100 랜덤
- 이길 수 있는 카드가 제한 시간 안에 나온다는 보장은 없다
- 라운드가 오를수록 상대 점수대와 제한 시간이 올라가 선택 압박을 만든다

추후 후보:

- 한 번 쓴 카드는 덱에서 제거
- 높은 카드를 지금 쓸지 아낄지 선택
- 낮은 카드로 이기면 보너스 배율
- 특정 라운드마다 카드 교체권 제공

## 상대 점수 공개 방식

현재 MVP는 초반 10라운드 동안 상대 점수를 완전 공개한다. 라운드 11부터는 좁은 범위 힌트를 보여주고, 라운드가 오를수록 범위 폭을 조금씩 넓힌다.

후보 A: 상대 점수 완전 공개

- 장점: 규칙이 즉시 이해된다.
- 장점: 시간 압박 속 빠른 비교 게임이 된다.
- 단점: 높은 카드가 있으면 선택이 너무 명확할 수 있다.

후보 B: 상대 점수 범위 공개

- 예: `상대 50-70`
- 장점: 운과 판단이 섞인다.
- 장점: "88을 써야 하나, 71로 충분할까" 고민이 생긴다.
- 단점: 첫 판 설명이 약간 필요하다.

후보 C: 상대 점수 비공개

- 장점: 도박성이 강하다.
- 단점: 플레이어가 실력보다 운으로 느낄 수 있다.
- 단점: 패배가 억울해질 수 있다.

추천 MVP:

- 라운드 1-10은 상대 점수를 완전 공개한다.
- 라운드 11은 2개 폭 범위, 라운드 12는 3개 폭 범위처럼 점진적으로 넓힌다.
- 완전 비공개는 첫 후보에서 제외한다.

## 난이도 설계

난이도는 두 축으로 올린다.

제한 시간:

- 1-3라운드: 5.0초
- 4-7라운드: 4.0초
- 8-12라운드: 3.0초
- 13라운드 이후: 2.4초

상대 점수대:

- 초반: 20-70 중심
- 중반: 35-85 중심
- 후반: 50-98 중심

점수대는 너무 빨리 빡세게 올리지 않는다. 이 게임의 재미는 "질 것 같은데 이겼다"이지, 매 라운드 벽을 만나는 느낌이 아니다.

## 점수 설계

기본 점수:

- 승리 시 선택한 내 카드 점수를 누적한다.
- 낮은 카드로 이길수록 효율이 좋다는 감각을 남긴다.

추후 후보:

- 상대 점수와 내 카드 차이가 작을수록 보너스
- 연승 보너스
- 제한 시간 절반 안에 고르면 스피드 보너스

MVP에서는 보너스를 넣지 않는다. 첫 판에서는 누적 점수 하나만 명확해야 한다.

## 실패와 피드백

승리:

- 내 카드와 상대 점수를 나란히 공개한다.
- 선택한 카드가 강하게 튀고 누적 점수가 올라간다.
- 바로 다음 라운드로 넘어간다.

패배:

- 상대 점수와 내 카드 점수를 크게 비교한다.
- 최종 Score와 Best Score를 표시한다.
- 다시하기 버튼을 제공한다.

시간 종료:

- 타이머가 0이 되면 현재 카드로 즉시 비교한다.
- 이 카드가 상대보다 낮거나 같으면 런이 종료된다.

## 화면 구성

MVP 화면:

- 상단: 현재 Score, Best Score, Round
- 중앙: 상대 점수 또는 좁은 상대 점수 범위
- 하단: 스와이프 가능한 현재 카드 1장
- 화면 한쪽: 제한 시간 게이지
- 실패 패널: Score, Best, Again

비주얼은 `docs/visual-direction.md`의 손그림 스케치 방향을 따른다. 숫자가 핵심이므로 카드의 점수 가독성을 가장 우선한다.

- 낮은 카드로 이겼을 때 보너스가 필요한가?
- 패배 직전까지 얻은 누적 점수만 기록하는 방식이 충분히 명확한가?
- 이름 `도파민 스왑`을 유지할지, 영어 배포명 `Dopamine Swap`을 쓸지?
