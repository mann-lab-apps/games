# 게임 1차 출시 기준, 추가 개발 판단, 확장 방향 기준

기준일: 2026-09-01  
참조 문서: `docs/supercent-game-production-standards.md`, `docs/supercent-fit-current-vs-potential-evaluation.md`

## 1. 운영 원칙

우리는 모든 게임을 Supercent식으로 만들 필요는 없다. 하지만 모든 게임은 최소한의 1차 출시 기준을 통과해야 한다. 그다음에는 "더 만들 것인가"를 먼저 판단하고, 더 만들 가치가 있는 게임에 한해서 "Supercent식으로 키울 것인가, 다른 방식으로 키울 것인가"를 판단한다.

따라서 기준은 3단으로 분리한다.

1. **1차 필터: 출시 실험 기본 자격**
   - Supercent식이든 아니든 모든 게임이 반드시 통과해야 한다.
   - 목적은 "이 게임을 유저에게 보여줘도 되는가"를 판단하는 것이다.

2. **2차 필터: 추가 개발 자격**
   - 1차 통과작 또는 조건부 통과작을 대상으로 평가한다.
   - 목적은 "이 게임에 며칠에서 몇 주의 개발 시간을 더 쓸 가치가 있는가"를 판단하는 것이다.
   - 이 단계에서는 Supercent식인지 아닌지를 아직 판단하지 않는다.

3. **3차 필터: 확장 방향 선택**
   - 2차를 통과한 게임만 대상으로 평가한다.
   - 목적은 "Supercent식 성장형으로 확장할지, 독립 출시/니치/퍼즐/아케이드식으로 확장할지"를 정하는 것이다.

4. **실측 필터: 출시 후 지표 판단**
   - CPI, D1, 세션 길이, 튜토리얼 이탈, 리뷰 리스크를 본다.
   - 목적은 "더 만들지, 방향을 바꿀지, 접을지"를 정하는 것이다.

## 2. 핵심 결론

추천 전략은 **작게 출시하고, 추가 개발 여부를 먼저 결정한 뒤, 맞는 확장 방식을 고르는 것**이다.

- 1차 기준은 모든 게임에 적용한다.
- 2차 기준은 "추가 개발할 가치"만 본다.
- 3차 기준에서 Supercent식, 독립 출시식, 니치/퍼즐식, 보류를 나눈다.
- 1차를 통과해도 2차에서 약하면 추가 개발하지 않는다.
- 2차를 통과해도 Supercent식이 약하면 독립 실험 트랙으로 둔다.
- 3차에서 Supercent식으로 맞는 게임만 성장 메타, UA 소재, 소프트런칭 준비에 집중 투자한다.

## 3. 1차 필터: 모든 게임이 반드시 통과해야 할 기준

1차 필터는 "Supercent스러움"보다 "기본 제품성"을 본다. 퍼즐, 아케이드, 액션, 감성 게임 모두 동일하게 적용한다.

### 3.1 1차 Must

아래 항목 중 하나라도 실패하면 1차 출시하지 않는다.

- **한 문장 설명 가능**
  - 10초 안에 "무엇을 조작해서 무엇을 달성하는 게임인지" 설명할 수 있다.
  - 예: "좌우 발을 눌러 펭귄을 걷게 하고 물고기를 모은다."

- **첫 10초 조작 이해**
  - 신규 유저가 첫 입력을 어디에 해야 하는지 화면만 보고 안다.
  - 첫 입력 후 0.2초 안에 캐릭터/오브젝트/점수/소리 중 최소 2개가 반응한다.

- **첫 60초 루프 완성**
  - 조작 -> 결과 -> 보상/피드백 -> 다음 행동이 60초 안에 한 번 이상 닫힌다.
  - Supercent식 업그레이드가 없어도 되지만, "한 번 더 할 이유"는 보여야 한다.

- **첫 보상 15초 이내**
  - 점수, 재화, 파괴, 성공 연출, 새 목표 중 하나가 15초 안에 발생한다.
  - 보상이 순수 텍스트만이면 부족하다. 시각/청각 피드백이 있어야 한다.

- **3분 이상 자연 플레이**
  - 설명 없이 3분 이상 플레이가 이어진다.
  - 3분 안에 "이제 뭘 하지?"가 나오면 실패다.

- **조작/판독 안정성**
  - 핵심 조작이 모바일 화면에서 안정적으로 동작한다.
  - UI가 플레이에 필요한 오브젝트를 가리지 않는다.
  - 실패 이유가 플레이어에게 납득 가능해야 한다.

- **기본 완성도**
  - 시작, 플레이, 결과, 재시작 흐름이 끊기지 않는다.
  - 크래시, 무한 로딩, 진행 불가, 저장 데이터 손상 같은 치명 버그가 없다.
  - 사운드/진동/시각 피드백 중 최소 2개가 핵심 행동에 붙어 있다.

- **기본 계측**
  - 최소 이벤트가 기록된다.
  - 필수 이벤트: `app_open`, `run_start` 또는 `level_start`, `first_action`, `first_reward`, `run_end` 또는 `level_end`, `session_end`

- **스토어/광고 최소 소재**
  - 실제 게임 장면 기반 스크린샷 3장 이상을 만들 수 있다.
  - 15초 플레이 영상 1개를 만들 수 있다.

### 3.2 1차 Should

- 첫 30초 안에 보상이 2회 이상 발생한다.
- 첫 3분 안에 난이도, 목표, 보상 중 하나가 변화한다.
- 첫 세션에서 재시작 또는 다음 스테이지 진입이 자연스럽다.
- 실패 화면이 "다시 하면 될 것 같다"로 느껴진다.
- 광고/IAP가 없더라도 나중에 넣을 자리가 UX상 자연스럽다.
- 10분 이상 반복 가능한 콘텐츠나 변주가 있다.
- 내부 5명 테스트에서 4명 이상이 별도 설명 없이 첫 목표를 이해한다.

### 3.3 1차 점수표

각 항목은 1-5점으로 평가한다.

| 항목 | 1점 | 3점 | 5점 |
| --- | --- | --- | --- |
| 설명 가능성 | 설명해도 헷갈림 | 한 문장 설명 가능 | 영상만 봐도 이해 |
| 첫 10초 조작 | 어디를 눌러야 할지 모름 | 첫 입력은 가능 | 즉시 조작과 목표 이해 |
| 첫 60초 루프 | 피드백/목표 없음 | 기본 루프 1회 완성 | 보상과 다음 목표가 명확 |
| 첫 보상 | 30초 이후 | 15초 이내 | 5-8초 이내 |
| 3분 플레이 | 1분 안에 막힘 | 3분은 가능 | 5분 이상 자연 |
| 조작감 | 입력/충돌 불안정 | 플레이 가능 | 손맛이 좋고 예측 가능 |
| 시각 명확성 | UI/오브젝트 혼란 | 구분 가능 | 작은 화면에서도 선명 |
| 완성도 | 치명 버그 있음 | 시작-결과 가능 | 출시 실험 가능 |
| 계측 | 없음 | 핵심 이벤트 있음 | 퍼널/이탈 분석 가능 |
| 소재화 | 스크린샷 애매 | 스크린샷/영상 가능 | 광고 소재 3개 가능 |

### 3.4 1차 통과 판정

| 판정 | 조건 | 액션 |
| --- | --- | --- |
| 통과 | Must 전부 충족, 평균 3.2 이상, 조작감/첫 60초/완성도 각 3점 이상 | 1차 출시 또는 제한 테스트 |
| 조건부 통과 | Must 1개 이하 미흡, 평균 3.0 이상 | 2-3일 수정 후 재평가 |
| 보류 | Must 2개 이상 미흡 또는 평균 3.0 미만 | 출시하지 않음 |
| 폐기 검토 | 한 문장 설명, 첫 10초 조작, 3분 플레이 중 2개 이상 실패 | 코어 재설계 |

## 4. 2차 필터: 추가 개발할지 판단하는 기준

2차 필터는 Supercent식 여부를 보지 않는다. 이 단계의 질문은 하나다.

**"이 게임을 더 만들면 결과가 좋아질 가능성이 충분한가?"**

좋은 게임이라도 추가 개발 레버가 없으면 2차에서 멈출 수 있다. 반대로 Supercent식은 아니어도 D1, ASO, 니치, 퍼즐 완성도, 유료/광고 수익 실험 가능성이 있으면 추가 개발 대상이 될 수 있다.

### 4.1 2차 Must

- **개선 레버가 명확하다**
  - 무엇을 고치면 지표가 좋아질지 3개 이하의 핵심 작업으로 설명 가능하다.
  - 예: 첫 세션 보상 강화, 튜토리얼 단축, 콘텐츠 10개 추가, 광고 소재 재촬영.

- **추가 개발 대비 효과가 크다**
  - 2-5일 작업으로 1차 기준의 약점이 눈에 띄게 개선된다.
  - 1-2주 작업이면 출시 후 지표를 다시 볼 만한 변화가 생긴다.

- **첫 세션 또는 재방문 이유가 있다**
  - 첫 세션이 재미있거나, 다시 하면 더 잘할 수 있거나, 다음 목표가 보인다.
  - 이유가 "언젠가 메타를 붙이면 좋을 것"뿐이면 부족하다.

- **품질 부채가 감당 가능하다**
  - 조작, 카메라, UI, 저장, 빌드, 계측 중 치명적 재작업이 2개 이하이다.
  - 핵심 코어를 갈아엎어야 하면 추가 개발이 아니라 재기획이다.

- **실측 가능한 가설이 있다**
  - 추가 개발 후 어떤 지표가 좋아져야 하는지 명확하다.
  - 예: 첫 60초 이탈 감소, 세션 길이 증가, 재시작률 증가, CPI 개선, 평점 리스크 감소.

- **콘텐츠 또는 운영 확장 여지가 있다**
  - 최소 10-20분 플레이를 만들 수 있는 레벨/미션/변주/스테이지/난이도 구조가 있다.
  - 단일 트릭만 있고 반복 설계가 불가능하면 추가 개발 우선순위가 낮다.

### 4.2 2차 Should

- 내부 5명 테스트에서 3명 이상이 "한 번 더 해보고 싶다"고 말한다.
- 첫 세션 3분 이상이 안정적으로 나온다.
- 플레이 실패 후 재시작 버튼을 누르는 흐름이 자연스럽다.
- 수익화 또는 스토어 테스트 목적이 명확하다.
- 팀이 1주 안에 주요 약점을 고칠 수 있다고 판단한다.
- 비슷한 게임 3개 이상과 비교했을 때 차별점이 있다.

### 4.3 2차 점수표

| 항목 | 1점 | 3점 | 5점 |
| --- | --- | --- | --- |
| 개선 레버 | 뭘 고칠지 불명확 | 약점 2-3개가 보임 | 적은 작업으로 큰 개선 가능 |
| 개발 대비 효과 | 작업량 대비 변화 작음 | 며칠 수정 가치 있음 | 1주 투자 가치 높음 |
| 첫 세션 힘 | 첫 플레이가 약함 | 3분 플레이 가능 | 바로 재시작하고 싶음 |
| 재방문 이유 | 없음 | 점수/스테이지 재도전 | 목표/성장/숙련 이유 명확 |
| 품질 부채 | 핵심 재작성 필요 | 일부 정리 필요 | 지금 구조로 확장 가능 |
| 실측 가능성 | 무엇을 볼지 모름 | 기본 지표 가능 | 가설과 이벤트가 명확 |
| 콘텐츠 여지 | 단일 트릭 | 10분 변주 가능 | 20분 이상 확장 가능 |
| 소재/스토어 여지 | 보여줄 장면 약함 | 스크린샷/영상 가능 | 여러 소재 테스트 가능 |
| 수익화 여지 | 넣기 어색함 | 광고/상품 자리 있음 | 수익화가 플레이와 자연 연결 |
| 팀 확신 | 계속 만들 이유 약함 | 실험해볼 만함 | 다음 스프린트 주력 가능 |

### 4.4 2차 통과 판정

| 판정 | 조건 | 액션 |
| --- | --- | --- |
| 추가 개발 | 평균 3.6 이상, 개선 레버/첫 세션 힘/품질 부채 각 3점 이상 | 3차 확장 방향 판단으로 이동 |
| 짧은 리워크 | 평균 3.2 이상, Must 1-2개 미흡 | 2-5일 수정 후 2차 재평가 |
| 유지 실험 | 1차는 통과했지만 2차 평균 3.2 미만 | 큰 개발 없이 출시/ASO/소재 실험만 |
| 보류 | 1차도 애매하고 추가 개발 레버도 약함 | 추가 리소스 중단 |
| 재기획 | 핵심 코어 교체가 필요 | 새 콘셉트로 다시 1차 평가 |

## 5. 3차 필터: Supercent식 또는 다른 방식으로 확장할지 판단하는 기준

3차 필터는 2차에서 "추가 개발 가치 있음" 판정을 받은 게임만 대상으로 한다. 이 단계에서는 어떤 방식으로 키울지 결정한다.

### 5.1 Supercent식 확장 기준

Supercent식 확장은 낮은 CPI, 즉시 이해, 첫 5분 성장, 반복 가능한 메타가 핵심이다.

Must:

- 10초 무음 광고 영상만으로 목표, 조작, 보상, 성장 가능성이 보인다.
- 왜 CPI $1 미만을 노릴 수 있는지 문장으로 설명 가능하다.
- 첫 60초 안에 조작 -> 보상 -> 업그레이드 또는 성장 -> 다음 목표가 보인다.
- 첫 5분 안에 최소 3번의 성장 신호가 있다.
- 능력, 공간, 자동화, 장비, 수집, 미션, 스킨 중 3개 이상의 성장 축이 있다.
- 20분 이상 반복 가능한 콘텐츠로 확장 가능하다.
- 보상형 광고 명분이 최소 2개 이상 자연스럽다.
- 첫 3분 동안 강제 광고를 노출하지 않는다.

Supercent식으로 가기 좋은 게임:

- 약한 캐릭터/작은 공간/낮은 능력이 점점 커진다.
- 조작이 한 손으로 즉시 이해된다.
- 보상 숫자, 파괴, 수집, 확장이 화면에서 바로 보인다.
- 광고 소재 5종 이상을 만들 수 있다.

### 5.2 독립 출시/니치 확장 기준

Supercent식으로 약해도, 다음 기준이 강하면 독립 출시 또는 니치 실험으로 확장한다.

Must:

- 첫 플레이 만족도가 높다.
- 규칙 완성도 또는 조작 손맛이 좋다.
- 스토어 검색/ASO/커뮤니티/퍼즐/챌린지 등 다른 유입 경로가 있다.
- 성장 메타가 없어도 재도전, 숙련, 기록, 스테이지 클리어 욕구가 있다.
- 추가 개발이 제품 완성도와 평점 방어에 직접 기여한다.

독립식으로 가기 좋은 게임:

- 2048 변주, 숫자 퍼즐, 짧은 챌린지, 감성 아케이드.
- CPI 대박보다 낮은 개발비, 안정적 완성도, ASO, 평점, 광고 수익 실험이 목표인 게임.
- Supercent식 메타를 억지로 붙이면 오히려 게임이 탁해지는 경우.

### 5.3 훅 검증/재기획 기준

다음 조건이면 제품 확장보다 훅 검증 또는 재기획을 먼저 한다.

- 10초 소재는 강하지만 현재 게임 구조가 얕다.
- 첫 조작/첫 세션이 약해서 출시하면 이탈이 클 것 같다.
- 코어는 재미있지만 테마가 맞지 않는다.
- 메타를 붙이기 전에 대중 소재 반응을 먼저 봐야 한다.

이 경우 1-2일 안에 광고용 플레이 장면이나 짧은 playable만 만들고, 제품 개발은 지표나 내부 반응을 본 뒤 결정한다.

### 5.4 3차 방향 판정표

| 판정 | 조건 | 액션 |
| --- | --- | --- |
| Supercent 확장 | Supercent식 Must 대부분 충족, 10초 훅/첫 5분 성장/메타 확장성이 강함 | 성장 메타, UA 소재, 소프트런칭 준비 |
| Supercent 리워크 | 훅은 강하지만 첫 60초/첫 5분/메타가 부족 | 3-5일 리워크 후 재평가 |
| 독립 출시 확장 | 제품성은 좋지만 Supercent식 CPI/메타와 맞지 않음 | ASO, 스테이지, 품질, 광고 수익 중심 |
| 훅 검증 | 소재는 강하지만 제품 구조가 약함 | 10초 영상/playable 먼저 테스트 |
| 재기획 | 2차는 통과했지만 현재 테마/구조가 확장 방향과 충돌 | 새 테마 또는 새 코어로 재작성 |

## 8. 제작자/AI 에이전트에게 줄 공통 완료 기준

아래 문장은 모든 신규 게임 제작 프롬프트에 넣는다.

```text
이 게임은 Supercent식으로 확장할 수도 있고 독립 출시 실험으로 남을 수도 있지만, 반드시 1차 출시 기준을 통과해야 한다. 기준은 1차 출시 자격, 2차 추가 개발 자격, 3차 확장 방향 선택으로 분리한다.

1차 출시 기준:
- 10초 안에 조작과 목표가 이해되어야 한다.
- 첫 입력 후 0.2초 안에 명확한 반응이 있어야 한다.
- 첫 15초 안에 보상이 발생해야 한다.
- 첫 60초 안에 조작 -> 결과 -> 보상/피드백 -> 다음 행동 루프가 닫혀야 한다.
- 설명 없이 3분 이상 자연스럽게 플레이되어야 한다.
- 시작, 플레이, 결과, 재시작 흐름이 끊기면 안 된다.
- 모바일 화면에서 UI가 핵심 오브젝트와 조작 영역을 가리면 안 된다.
- 최소 이벤트 `app_open`, `run_start/level_start`, `first_action`, `first_reward`, `run_end/level_end`, `session_end`를 기록해야 한다.
- 실제 게임 장면 기반 스크린샷 3장과 15초 플레이 영상 1개를 만들 수 있어야 한다.

2차 추가 개발 기준:
- 무엇을 고치면 좋아질지 3개 이하의 핵심 개선 레버로 설명할 수 있어야 한다.
- 2-5일 또는 1-2주 추가 작업으로 지표나 완성도가 눈에 띄게 좋아져야 한다.
- 첫 세션 만족, 재시작 욕구, 재방문 이유 중 최소 하나가 분명해야 한다.
- 조작, 카메라, UI, 저장, 빌드, 계측 부채가 감당 가능해야 한다.
- 추가 개발 후 확인할 지표 가설이 있어야 한다.
- 최소 10-20분 이상의 콘텐츠 또는 변주로 확장 가능해야 한다.

3차 확장 방향 기준:
- Supercent식으로 갈 경우, 10초 무음 광고에서 목표/조작/보상/성장이 보여야 한다.
- Supercent식으로 갈 경우, CPI $1 미만 가능성과 첫 5분 성장 3회 이상, 성장축 3개 이상이 필요하다.
- Supercent식으로 갈 경우, 보상형 광고 명분 2개 이상과 첫 3분 강제 광고 없음 기준을 만족해야 한다.
- 독립 출시로 갈 경우, Supercent식 메타보다 규칙 완성도, 조작 손맛, ASO, 챌린지, 평점 방어, 낮은 개발비의 장점이 분명해야 한다.
- 훅만 강하고 제품 구조가 약한 경우, 제품 개발보다 10초 영상 또는 playable 훅 검증을 먼저 해야 한다.

완료 후에는 1차 점수표, 2차 추가 개발 점수표, 3차 확장 방향 판정을 각각 작성하고, 이 게임을 `Supercent 확장`, `Supercent 리워크`, `독립 출시 확장`, `훅 검증`, `유지 실험`, `보류`, `재기획` 중 하나로 판정한다.
```

## 9. 최종 운영 룰

앞으로는 다음 룰을 기본값으로 둔다.

- 모든 게임은 1차 필터를 통과해야 출시 실험 대상이 된다.
- 1차 필터는 Supercent식이 아니라 기본 제품성 기준이다.
- 2차 필터는 "더 만들 가치가 있는가"만 판단한다.
- 3차 필터에서 Supercent식, 독립 출시식, 훅 검증, 재기획을 나눈다.
- 1차 통과, 2차 실패 게임은 큰 개발 없이 유지 실험만 한다.
- 2차 통과, 3차 Supercent 실패 게임은 버리는 것이 아니라 독립 확장 트랙으로 둔다.
- 3차 Supercent 통과 게임만 성장 메타, UA 소재, 소프트런칭 준비에 집중 투자한다.
