# Rainwalker

Unity mobile mini-game prototype about keeping a doodle walker dry by dragging a sketch umbrella into angled rain.

## Project

- Unity editor: 6000.3.22f1
- Platform: Android
- Package name: com.mannlab.games.rainwalker
- Namespace: MannLab.Games.Rainwalker

## First Open

Open this directory from Unity Hub. Unity may generate missing project settings on first import.

## Prototype Scope

- 30 second portrait round with Ready, Playing, and Result states.
- Doodle person, umbrella, rain, splash, wet mark, and wind-line visuals are generated with UGUI meshes.
- Drag/mouse input rotates the umbrella with smoothing and angle limits.
- Rain direction flips between diagonal directions at random intervals and ramps in speed/density.
- Umbrella and body collision are separate from the hand-drawn visuals for stable scoring.
